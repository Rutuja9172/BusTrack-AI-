
# BusTrack AI

## Project Title
Real-Time Intelligent Public Transport Tracking and AI-Based Arrival Prediction System for Small Cities.

## Project Overview
BusTrack AI is an intelligent public transportation platform that provides real-time bus tracking, AI-based arrival predictions, route information and passenger journey assistance.

## Technology Stack
- React.js
- Tailwind CSS
- Python FastAPI
- MySQL 8
- SQLAlchemy
- WebSocket
- Scikit-learn
- Leaflet
- OpenStreetMap

## Development Modules

1. Passenger Application
2. Driver and Admin Application
3. Backend, Database and AI/ML

## Project Structure

- frontend/
- backend/
- ai-ml/
- documentation/

## Team
Three developers working on independent modules.

Development in progress.
